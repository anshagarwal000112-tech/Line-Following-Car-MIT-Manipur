# 🤖 5IR Line Follower Robot Using ESP32

A compact and efficient **5IR Line Follower Robot** built using an **ESP32** as the main controller. The robot uses 5 digital IR sensors to detect the track and controls two geared motors using an L298N motor driver.

The robot was designed, coded, assembled, and tested successfully. It is capable of following lines and handling **curves, loops, and 90-degree turns** smoothly.

## ⚙️ Working Principle

The IR sensors detect the difference between the black line and the surface.

The sensor values are processed by the ESP32, which controls the robot's movement and sends signals to the L298N motor driver.

The motor driver controls the speed and direction of both motors to keep the robot aligned with the line.
